# Online Stationery Management System — Stationery Treasures

**Project:** B.Sc. Computer Science final-year project  
**Academic year:** 2023–2024  
**Author:** Abhishek Balkrishna Raut

## Overview

Stationery Treasures is a web-based stationery shopping and order-management project. It presents stationery products and documents customer ordering and administration workflows.

## Documented features

### Customer
- User registration and login.
- Product browsing.
- Shopping-cart management.
- Checkout and order placement.
- Receipt generation.

### Administration
- Product and category management.
- Product price management.
- Customer-order management and order-status updates.

## Technology stack documented for this project

- HTML5 and CSS3
- JavaScript and jQuery
- PHP
- PostgreSQL
