# Online Stationery Management System — Stationery Treasures

**Project:** B.Sc. Computer Science final-year project  
**Academic year:** 2024–2025  
**Author:** Abhishek Balkrishna Raut

## Overview

Stationery Treasures is a web-based stationery shopping and order-management project that displays products and supports online ordering.

## Main features described in the project

### Customer
- Registration and login
- Product browsing
- Shopping-cart management
- Checkout and order placement
- Receipt generation

### Administration
- Product and category management
- Product price management
- Customer-order management and order-status updates

## Technology stack

- HTML5 and CSS3
- JavaScript and jQuery
- PHP
- PostgreSQL
