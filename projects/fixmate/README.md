# FixMate — Premium Home Services Platform

**Project:** M.Sc. Computer Science project  
**Academic year:** 2025–2026  
**Author:** Abhishek Balkrishna Raut

## Overview

FixMate is a responsive front-end prototype for browsing household services and creating a booking request. The documented service categories include cleaning, electrical repair, plumbing, pest control, and vehicle services.

## Features in the documented prototype

### Customer-facing flow
- Browse a service catalogue with category filters.
- View service cards, displayed pricing, and estimated duration.
- Open a booking form and enter date, time, and address details.
- Review an order summary.
- View login, registration, and password-recovery interfaces.
- Explore a customer dashboard interface.

### Admin-facing interface
- View a dashboard for bookings.
- Manage service information through the admin interface.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Responsive design
- Proposed MySQL schema for users, services, and bookings
- Visual Studio Code and Git/GitHub

## Implementation status and limitations

The submitted prototype uses in-memory JavaScript data. Live database connectivity and backend APIs are future scope. The project documentation does not claim a deployed production backend, persistent booking storage, or working server-side authentication.
