# FixMate — Premium Home Services Platform

**Project:** M.Sc. Computer Science final-year project  
**Academic year:** 2025–2026  
**Author:** Abhishek Balkrishna Raut

## Overview

FixMate is a responsive front-end prototype for browsing household services and creating a booking request. The service categories include cleaning, electrical repair, plumbing, pest control, and vehicle services.

## Main features described in the project

- Service catalogue with category filters, service cards, pricing, and estimated duration.
- Booking modal to collect date, time, and address details and present an order summary.
- Login, registration, and forgot-password interfaces.
- Separate customer and admin views, including a customer dashboard and an admin panel for viewing bookings and managing service information.
- Proposed relational schema for users, services, and bookings.

## Technology stack

- HTML5 and CSS3
- Vanilla JavaScript (ES6)
- Responsive design
- Proposed MySQL schema design
- Visual Studio Code and Git/GitHub

## Implementation status

The submitted prototype uses in-memory JavaScript data. Live database connectivity and backend APIs are future scope; this page does not claim that a production backend is deployed.
