# Abhishek Raut — Portfolio Website

A personal portfolio website for presenting my background, selected work, and contact details.

🌐 **Live website:** https://abhishekrautportfolio.space-z.ai  
💻 **GitHub profile:** https://github.com/abhishekraut7391  
🔗 **LinkedIn:** https://www.linkedin.com/in/abhishek-raut-372021311/

## Built with

- HTML5 and CSS3
- Bootstrap 5
- JavaScript
- AOS animation library
- Particles.js background effects
- Typed.js text animation
- Font Awesome icons and Google Fonts

## What's included

- Responsive one-page layout
- Dark and light theme toggle
- Navigation, about, skills, projects, education, and contact sections
- Portfolio images in `images/`
- Resume PDF in `resume/resume.pdf`

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser.
3. Keep an internet connection available for third-party assets loaded from CDNs.

## Notes

This repository is a work in progress. The contact form currently uses a front-end demo interaction; it needs an email service or backend integration before it can deliver messages. Review all links and content before using the site for job applications.
